# Citation guidance / 인용 안내

Use the original sources for scientific claims: [bibliography](references/BIBLIOGRAPHY.md) and [BibTeX](references/references.bib). The report itself is an AI-assisted research synthesis, not a peer-reviewed publication. No human authors, affiliations, ORCIDs or report DOI have been invented.

Suggested repository citation fields to complete before publication:

```text
[Actual author or organization]. Data-Efficient Biological and Neural AI Research:
Literature Review, Failure Modes, and Proposed Validation Architecture.
Version 1.0.0, 2026-09-22. [Actual repository URL and commit or archive DOI].
```

실제 저자·기관·저장소 주소가 확정되면 대괄호 항목을 교체한다. 원논문은 해당 원저자와 DOI로 인용하고, 제안 구조의 실증 상태를 명시한다.
