# Validation scope / 검증 범위

Executed for this package:

- Synthetic GP example: 20 seeds × 2 scenarios × 2 acquisition policies × 4 budgets = 320 budget-level records; 16 aggregate records; 4 figures.
- Internal JSON parsing, unique reference IDs, bilingual chapter parity, portable citations, local link targets, and bibliography anchors.
- JSON Schema positive fixtures and deliberate negative provenance fixture.
- Numerical GP and schema regression tests: 14 tests passed. Actual output: [test log](unittest.log).
- ZIP CRC check and SHA-256 inventory during packaging.

[Machine-readable validation report](validation_report.json) · [Demo environment](../examples/results/environment.json)

**Not validated:** every external URL, every upstream license/version, third-party code execution, real biological performance, foundation fine-tuning, clinical safety, institutional permissions, or prospective experiments. Mermaid source was inspected for structure but was not rendered in a live GitHub browser. Korean/English documents are independently authored paired explanations rather than a certified legal translation.

위 점검은 패키지 구조·수치 예제의 검증이다. 제안한 전체 AI 시스템이나 생물학적 기전이 검증되었다는 뜻이 아니다. 원격 GitHub 업로드는 수행하지 않았다.
