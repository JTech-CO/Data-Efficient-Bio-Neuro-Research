# Changelog

## 1.1.0 · 2026-09-22 · Additive synthetic research implementation

한국어: 원 문헌 조사와 연구 계획을 보존하고 연구 방향을 시험하는 실행 코어·한영 웹 실험실·504회 합성 파일럿을 추가했다. 프로덕션 또는 생물학 검증 버전이 아니다.

English: preserves the original research plan and adds an executable core, bilingual workbench, and 504-run synthetic pilot. Not a production or biologically validated release.

- Separate immutable measurement provenance, revisable assumptions, and costed query proposals.
- Exact GP, observation-aware Bayesian linear regression, a finite mechanism committee, and a joint multifidelity GP.
- Training/diagnostic/final-test boundaries, candidate-abstention state, assumption stopping, fidelity fallback, hash-linked events, and run audit.
- Nine synthetic scenarios; twelve paired seeds; 42 design cells including an identity-operator ablation. All outcomes retained.
- File/Pages replay; actual local Python execution; JSON import/export; Korean and English research documentation.
- Tests, source fingerprints, original-file preservation manifest, and an unexecuted remote CI configuration.

Original chapters, bibliography, schemas, examples, and historical QA files are not replaced. Root READMEs receive navigation; their exact old versions and the original checksum file are archived under research/baseline/. No remote repository changes, public deployment, or license reassignment are performed.
