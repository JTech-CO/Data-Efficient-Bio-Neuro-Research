## Historical preservation

Original cumulative READMEs are preserved byte-for-byte as [Korean](research/bounded/baseline/README.md) and [English](research/bounded/baseline/README.en.md) snapshots. Their relative links remain as originally written; use the table above for active navigation. [Baseline hashes](research/bounded/baseline/manifest.json) record the original files. Previous research documents, numerical code and results are unchanged.

This package follows the canonical Closed-Loop-Lab `research/closed_loop` lineage, not the earlier alternative `research_lab/` layout. Add future releases here rather than appending historical README bodies to the main page.
