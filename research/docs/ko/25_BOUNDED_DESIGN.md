# 25. 범위가 있는 증거: G/H/I 연구 설계

[English](../en/25_BOUNDED_DESIGN.md) · [Sources](../../bounded/references/REFERENCES.md) · [Research entry](../../../BOUNDED.md)


## 목적과 보존

v1.3의 후속 결정에서 제시한 세 질문을 작은 실행 연구로 옮겼다. G는 기준이 완전히 정확하다는 가정을 풀고, H는 알려진 잡음 분산에 의존하지 않는 대조 진단을 비교하며, I는 기술적 반복의 차이와 평균을 분리한다. 새 모듈은 `research/bounded_loop/`다. 기존 01~24장과 기존 코어·결과·화면은 보존하고 README의 누적 버전 설명만 별도 `VERSIONS.md`로 옮긴다.

생물학적 관측은 0개다. 잠재 반응·센서·표준 첨가는 무차원 합성 변수이며 실제 물질의 농도, 투입량 또는 실험실 조작 지침이 아니다. 세 모듈은 동일한 증거 역할·실행 기록 규칙을 공유하지만 하나의 자동 생물 연구자가 아니다.

## 평가 전에 고정한 범위

| 과제 | 세계 유형 | 고정 요인 | 실행 수 |
|---|---|---|---:|
| G | 정상, 범위 내 편향, 공통 범위 내/밖 편향, 비선형 센서, 상관 반복 | 세 측정 설계, 같은 비용 72, 각 유형 40세계 | 720 |
| H | Gaussian, 이분산, 대칭 t3, 비대칭 평균 0, 상관 반복, 넓은/좁은/약한 효과, 공통모드 | 비진단 기준 + 두 정책 × 세 진단 비중, 총 수집 상한 144 | 6,720 |
| I | 정상, 이분산, 평균 누락, 복합, 국소 누락, 오염, 공유 배치, 반복 내 드리프트 | 2/4/6회 반복, 같은 관측 48, 각 유형 32세계 | 768 |

G는 동일 자료에서 편향 폭 0/기본/2배를 각각 계산한다. H의 세 검정도 같은 관측을 공유한다. I의 다섯 최종 분석은 같은 반복 자료에 적용하며 64회 모수적 bootstrap 적합을 별도로 수행한다. 이 재계산을 새 독립 관측으로 세지 않는다.

60개 개발 실행과 단위 테스트 이후 코드·설정·계획을 로컬 해시로 고정했다. 평가 세계 ID와 잡음 난수열은 개발과 다르지만 함수 가족은 개발자에게 알려져 있다. 독립 사전등록이나 외부 블라인드 평가는 아니다. 결과 이후의 해석은 30장에 두며 숫자 코어나 임계값을 최종 결과에 맞춰 변경하지 않았다.

## 질문과 반증 조건

G: 선언한 편향 한계와 반복 가정이 맞는데도 가능한 집합이 참값을 체계적으로 배제하는가? 잡음을 0으로 줄여도 남는 범위를 숨기거나, 범위 밖 공통 편향에서 집합이 존재한다는 사실을 진실성으로 표시하면 실패다.

H: 새 위치의 반복 대조로 분산을 추정하거나 부호만 사용했을 때 오경보와 검정력·비용은 어떻게 달라지는가? 평균 0과 부호균형은 서로 다른 귀무다. 강한 반복 상관, 비대칭 평균 0, 공통모드를 반드시 별도 반례로 남긴다.

I: 같은 위치의 반복 차이로 잡음을 추정하고 작은 사전 고정 평균 기저를 추가했을 때, 오차 개선과 구간 확장을 구분할 수 있는가? 공유 배치오차나 반복 내 드리프트를 독립 기술잡음으로 잘못 이름 붙이면 실패다.

## 증거·비용·평가 분리

`fit / audit / final` 역할과 `source=simulated`, 기술적 반복 종류를 기록한다. H의 진단은 학습에 넣지 않으며 모델은 진단 전에 적합한 그대로다. I의 bootstrap을 포함한 모든 적합은 최종 관측 생성 전에 끝난다. G의 잡음 없는 평가 범위와 참 파라미터는 평가 전용이며 최적화 입력으로 사용하지 않는다.

G는 최종 실험값을 추가로 수집하지 않고 평가자가 참값으로 집합 포함을 판정한다. H/I는 81개 별도 관측을 수집하고 그 비용을 따로 합산한다. H의 설치·이동 비용은 관측인 척하지 않고 별도 장부에 남긴다. 예산 잔액을 숨기지 않으며 같은 상한과 정확히 같은 지출을 구분한다.

## 구현 범위

G는 고정 affine 역교정과 선형 평균의 다면체다. H는 제한된 위치 정책·대조 검정과 2차 예측기다. I는 고정 2차 평균, `sin(pi*x)` 하나의 잔차 기저, 2계수 로그분산을 다룬다. ODE·SINDy·PINN·파운데이션 학습·실제 데이터 업로드를 추가하지 않았다.
