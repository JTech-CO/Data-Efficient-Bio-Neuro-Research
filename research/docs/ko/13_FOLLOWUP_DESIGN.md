# 13. 후속 연구 A·B: 오류를 감지하는 것과 원인을 구분하는 것

[English](../en/13_FOLLOWUP_DESIGN.md) · [이전 방향](12_RESEARCH_DIRECTION.md) · [수학·실험 명세](14_DIAGNOSTIC_PROTOCOL.md) · [실제 결과](15_FOLLOWUP_RESULTS.md)

## 이번 버전의 질문

v1.2.0-research.1은 기존 01~12장을 고치지 않고, 이전 문서의 연구 작업 A와 B를 실행으로 확장한다. 질문은 “가정이 틀렸는가?”, “무엇이 틀렸을 가능성이 있는가?”, “이를 구분하려면 다음에 어떤 측정을 해야 하는가?”이다. 새 바이오 파운데이션 모델, 신경 동역학의 발견, 임상적 진단이나 자동 실험 장치를 만드는 단계는 아니다.

실측과 측정계의 관계를 함께 모델링하는 접근은 이미 생명공학에 구현되어 있다. calibr8·murefi 연구는 측정값의 보정과 잡음 likelihood를 명시적으로 다뤘다. 또한 센서 보정에 해당하는 매개변수와 모형의 미설명 부분은 서로 혼동될 수 있다. 이번 구현의 동기는 이 기존 문제이며, 새로운 회귀 이론의 발명이라는 주장은 하지 않는다. [D01](../../followup/references/REFERENCES.md#d01) [D02](../../followup/references/REFERENCES.md#d02)

## 두 연구를 분리한다

**연구 A: 진단기만 평가.** 다음 조건을 언제 고르는지는 고정하고, 정상/고장 합성 세계에서 경고 기준 자체의 오경보·누락을 측정한다. 모든 진단법은 같은 측정과 같은 체크포인트를 공유한다. 여기서 능동 수집이 섞이지 않으므로 임계값 변경의 효과를 확인할 수 있다.

**연구 B: 측정 설계와 추정.** 센서 gain·offset과 잠재 반응 계수가 모두 미지인 계를 만든다. 표준값 교정, 일반 측정, 알려진 합성 개입을 비용이 다른 행동으로 둔다. 동일한 관측 집합을 여러 추정기로 다시 계산하여 “잘 골랐기 때문”과 “잘 해석했기 때문”을 분리한다. 특정 정보이득 정책을 승자로 가정하지 않고 간단한 교정-후-회귀와 비교한다.

E-ALPIPE처럼 식별가능성을 목표로 수집을 고르는 방법은 이미 존재하지만, 이번의 국소 정보량 목적함수는 그 알고리즘을 재현한 것이 아니다. 실제 시냅스 기록에 적용된 능동학습도 있지만 이번 버전에는 그 데이터나 알고리즘을 넣지 않았다. [D03](../../followup/references/REFERENCES.md#d03) [D07](../../followup/references/REFERENCES.md#d07)

## 연구용 세계와 공개되는 정보

개발 세계와 임계값 보정 세계의 기본 특징은 `phi(x)=x`이다. 평가 세계는 `tanh(1.5x)/tanh(1.5)`와 `0.65x+0.35x^3`을 번갈아 사용한다. 세계마다 계수·오류 강도·방향·잡음이 달라진다. 단, 어떤 phi를 사용하는지는 모델에 제공한다. 따라서 이 차이를 “알 수 없는 함수 family를 스스로 발견했다”거나 새로운 생물학 도메인으로 전이했다고 해석하지 않는다. 별도의 `local_bump`는 예측 모형의 기저에 없는 국소 변화를 넣는다.

| 시나리오 | 위반시키는 가정 | 기대하는 실패 또는 점검 |
|---|---|---|
| normal | 없음 | 전체 순차 경고의 오경보 |
| gain_offset | 센서 gain·offset | 교정으로 분리 가능한가 |
| mechanism | 기준 모형에 없는 개입 반응 | 센서 보정과 구분되는가 |
| noise_scale | 명목보다 큰 잡음 | 반복 측정이 잡음을 드러내는가 |
| combined | 센서·기전·잡음 동시 변화 | 단일 원인 강제 분류의 위험 |
| nonlinear_sensor | 비선형 센서 | 기전 잔차와 센서 오류가 함께 보이는가 |
| heteroscedastic | 위치마다 다른 잡음 | 등분산 검정·구간의 제한 |
| heavy_tail | 정규성 위반, 동일 분산의 t(3) | 분산만 맞춰도 진단이 충분한가 |
| local_bump | 진단 지점 사이의 국소 변화 | 고정 패널의 사각지대 |
| reference_mismatch | 표준 교정과 실제 표본의 센서 관계가 다름 | 표준이 통과해도 표본은 틀릴 수 있는가 |

정상 세계에서 경고가 없었다는 것은 “가정 검증 완료”가 아니다. 특히 마지막 두 시나리오는 데이터가 더 있더라도 현재 측정 설계나 가정으로는 해결되지 않을 수 있다는 반례이다. 인과 추론의 negative control과 계측용 표준값은 동일한 기법이 아니다. 다만 대조군·표준을 본 과제로 연결하는 추가 가정을 검토해야 한다는 교훈은 유사하다. [D06](../../followup/references/REFERENCES.md#d06)

## 실행 상태와 저장소 경계

`research/diagnostic_loop/`은 새 계약을 사용한다. 기존 `research/closed_loop/`의 고정 시간·반복 제약을 몰래 완화하지 않았다. 기존 해시 로그/직렬화 유틸리티만 재사용한다. `Observation.origin`은 simulated만 허용하며 모든 `real_world_authorized` 값은 false다. 합성 관측과 반복 측정은 독립 생물 표본으로 계산하지 않는다.

출력의 세계 truth는 평가기가 결과를 채점할 때 저장한다. 수집 함수와 예측기는 World 객체나 고장 태그를 받지 않는다. 관측 가능한 값, 공개된 기저, 명목 잡음과 현재 posterior만 받는다. Python 모듈 경계는 실행 검사용 설계이지 악의적인 코드에 대한 보안 격리는 아니다.

## 가설과 반증 조건

| 가설 | 비교 | 불리한 결과가 나오면 |
|---|---|---|
| F1: 유한 반복 보정이 오경보를 줄인다 | naive / Bonferroni / 보정-bank max | 오경보 수치와 적용 가정을 공개하고 자동 인증을 하지 않음 |
| F2: 교정값이 gain·기전의 혼동을 푼다 | no_reference / 교정 허용 | 단순 반복으로 해소되지 않는 rank 결핍 유지 |
| F3: 블록별 능동 수집이 실용적이다 | reference_first / joint / block / 동일 총예산 no-audit | 더 복잡한 정책을 기본값으로 승격하지 않음 |
| F4: 불확실성 전파가 필요하다 | 동일 관측에서 calibration plug-in / 전파 / 고정잡음 | 구간의 넓이와 실제 포함률을 같이 보고 과도한 넓이도 비용으로 봄 |
| F5: 원인 판정은 경고와 다르다 | 알려진 실패 태그와 경고 채널 | 표준 전이 실패·국소 변화의 누락을 성공 사례에서 제외하지 않음 |

모든 가설의 결과는 15장에 기록한다. 시간 동역학, PINN/BINN/SINDy, 계층적 donor 효과, 실제 데이터 어댑터는 여전히 후속 과제다.
