## G 다음: 편향 범위의 외부 근거와 추가 측정의 가치

B를 데이터에 맞춰 좁히지 말고 범위 격자에 따른 민감도 지도를 남긴다. 추가 행동은 기술적 반복, 새 독립 교정 배치, 다른 연산자 세 가지로 분리한다. 반복은 표본구간만 줄이고, 독립한 근거는 식별 집합 자체를 줄일 수 있는지를 평가한다. 공통 편향이 모든 기준에 같이 작용하는 반례는 계속 유지한다. 현재 기준 gain=1 가정을 완화하려면 별도 비선형/선형-분수 최적화와 외부 보정 근거가 필요하다. 빈 이름의 플러그인만 추가하지 않는다.

**반증:** 선언 범위 안의 새 세계에서 전체 파라미터를 자주 제외하거나, 기술적 반복만 늘려 잡음 없는 구조적 폭 아래로 부당하게 축소한다면 채택하지 않는다. 범위의 외부 타당성을 모델 적합도로 인증하지 않는다.

## H 다음: 검정력·귀무가설·비용을 함께 설계

현재 부호 방법은 조건부 부호 균형을, local t는 위치별 Gaussian 반복을 검사한다. 위치/척도 검정의 타깃을 UI와 API에서 서로 다른 null ID로 명시한다. 분산·비대칭·공통모드를 동시에 허용하는 순간 더 약한 결론 또는 추가 측정이 필요한지 먼저 적는다. 새로운 단순 지역 부호 누적 방법을 비교할 수 있지만 같은 bank에서 경고 기준을 튜닝하지 않는다. 독립 검증 배치를 별도로 예약한다.

**반증:** 정상의 전제 충족 세계에서 경고가 높거나, 같은 실제 비용에서 local t/최대 공백에 대해 탐지와 예측이 함께 나빠지면 기본 경로로 승격하지 않는다. 이동비·세팅비를 포함한 예산 회계는 유지한다. 대조군을 통과하면 전체 모델이 맞다는 문구는 금지한다.

## I 다음: 기술적 반복과 독립 배치 반복을 교차

다음 최소 확장은 donor 모델이나 대형 신경망이 아니라 2수준 모형 Y_ijr=m(x_i)+a_ij+epsilon_ijr이다. 같은 배치의 기술적 반복 r과 독립 배치 j를 구별한다. 동일 비용에서 위치 수·독립 배치 수·기술적 반복 수를 요인으로 바꾼다. 배치 분산을 얻을 관측 없이 기술적 분산을 총분산이라고 부르지 않는다. 평균 기저는 기본·사전 지정 residual·추가 독립 검증 선택을 분리한다.

**반증:** 평균 오지정을 더 큰 배치 분산으로만 숨기거나, 정상의 작은 효과에서 추가 구조가 오차·proper score를 함께 악화시키면 단순 모형을 유지한다. 전체 배치가 공유하는 기준 편향은 이 모형으로도 해결되지 않으므로 G의 식별 가정과 연결해 보고한다.

## 범위와 저장소 운영

이번 G/H/I는 세 모듈을 서로의 증거로 순환 재사용하지 않는 분리 연구다. 통합 자동 실험자가 아니며 실제 생물학적 데이터, prospective 개입, 임상 사용, ODE/SINDy/PINN/BINN, 파운데이션 모델 학습은 범위 밖이다. H3 출처 분리 외 생성 증강 효능, H4 donor 일반화, H5 멀티피델리티 추가 검증은 수행하지 않았다.

메인 README에는 현재 릴리스와 작업 입구만 둔다. 역사적 변경과 버전별 실행 경로는 VERSIONS 문서에 추가하며 README에 과거 전문을 붙이지 않는다. 과거 수치·문서·원시 결과를 이번 결론에 맞춰 수정하지 않는다.
