# 16. 연구 결정: 오류를 고치기 전에 관측으로 구분 가능한지 확인한다

## 이번 버전의 결정

v1.2는 기존 작업 A(탐지기 평가)와 B(측정 종류 선택)의 제한된 실행이다. 새로운 관측모형·기전·잡음 오류가 한 신호로 섞이지 않도록 분리했지만, 원인 식별을 완성하지 않았다. 기존 01~12 문서는 결과에 맞춰 수정하지 않는다.

| 질문 | 결정 | 근거 및 경계 |
|---|---|---|
| 단순 반복 p<0.05를 기본 경고로 둘 것인가 | 채택하지 않음 | 정상 bank 38.5% 경고. 유한 예산 보정과 별도 교정 비교 유지 |
| 개발 bank 보정이 Bonferroni보다 낫다고 할 것인가 | 주장 보류 | 정상 평가 6.1% 대 5.5%; 이 bank에서 보정이 우월하지 않음 |
| 첫 경고에 자동 중단할 것인가 | 기본 경로로 채택하지 않음 | 감지한 효과가 이미 확장 모델에 들어 있고, 중단은 학습 기회를 제거할 수 있음 |
| 블록 표적 획득만 남길 것인가 | 비교 정책으로 유지 | gain·offset에서 공동 정보이득이 더 낮은 오차; no-audit와 비용 비교도 필요 |
| 동일 관측을 더 많이 반복하면 원인도 식별되는가 | 명시적으로 부정 | 표준·표본 불일치는 재매개화로 관측적 동치 |
| 지금 ODE·PINN·바이오 파운데이션으로 확장할 것인가 | 우선순위 뒤로 유지 | 고정 패널의 공간 사각지대와 교정 전달 문제가 먼저 남음 |

## 연구 작업 D: 교정의 전달 가능성을 검증하는 새로운 관측

**질문:** 교정 표준과 표본의 측정 법칙이 같은지, 모델 적합 잔차 외의 자료로 구분할 수 있는가?

합성 세계에 두 번째 관측 연산자 또는 알려진 표본 내 변화량을 추가하는 설계를 먼저 검토한다. 같은 센서가 같은 law를 따른다는 가정이 필요한 새 측정과, 실제로 그 가정을 시험하는 독립 측정을 구분한다. 예를 들어 알려진 증가량이 센서 gain을 분리해도 offset과 상태 절편은 여전히 섞일 수 있으므로 전체 rank와 동등한 해 집합을 계산한다.

**반증 조건:** 새 측정 역시 기존 행공간 안에 머물거나 그 교정 가정이 같은 원인으로 오염되면 원인 식별 개선이라고 주장하지 않는다. 정상 기준값을 모형이 생성해 실제 교정 증거로 재사용하는 경로는 금지한다.

**평가:** 관측적 동치 여부의 수식·수치 검사, 참 gain·offset·theta의 회복 오차, 관측법칙이 다른 세계의 누락률, 비용. ‘센서 경고=원인 확정’ 대신 `unresolved / identifiable-under-assumptions / contradicted` 상태를 비교한다. 이 명칭들은 다음 버전의 설계안이며 현재 코드 API로 주장하지 않는다.

## 연구 작업 E: 전체 영역을 보지 못하는 진단 패널의 한계

**질문:** 진단비를 줄이면서 국소 오류를 놓치지 않을 수 있는가?

현재 세 지점 패널과, 사전에 무작위화한 광역 진단 표본, 한정된 budget에서 점진적으로 영역을 덮는 설계를 비교한다. 예측용 능동 질의와 검증용 위치 선정의 데이터 접근권을 분리한다. 모델이 모르는 지점을 모형 불확실성만으로 선택하면 오지정된 과신을 반복할 수 있다.

**반증 조건:** 정상 세계의 오경보가 늘거나, 같은 총비용의 균일 진단보다 국소 오류 누락·예측 손실이 나아지지 않으면 복잡한 적응 진단을 채택하지 않는다. 새 진단의 시행 횟수·위치가 데이터에 의존하면 v1.2의 유한 고정 panel 보장을 그대로 재사용하지 않는다. 그때에만 적절한 순차 검정 또는 추가적인 별도 교정 bank를 설계한다. [D04](../../followup/references/REFERENCES.md#d04) [D05](../../followup/references/REFERENCES.md#d05)

## 연구 작업 F: 잡음 모형과 정책의 효과를 분리한다

현 코드는 기술적 반복으로 잡음 분산 하나를 추정해 likelihood·획득·예측에 전달하지만 이분산 함수나 tail 형태는 학습하지 않는다. 다음에는 같은 관측에 homoscedastic Gaussian, 간단한 분산함수, robust likelihood를 각각 맞춘다. 그 뒤 동일한 추정기에서 질의 정책만 교체한다. 즉 데이터셋 × 추정기 × 수집정책 요인을 분리한다.

**반증 조건:** 구간 폭만 커지고 proper score·오차·비용은 개선되지 않거나, 견고화가 정상·작은 효과의 감도를 크게 잃으면 기본값으로 승격하지 않는다. 작은 데이터에서 noise와 discrepancy를 유연한 잔차 함수 하나로 모두 설명하는 것도 별도 식별가능성 문제다. [D02](../../followup/references/REFERENCES.md#d02)

## 다음 평가 bank 운영

v1.2 생성기와 평가 결과는 이제 개발 자료다. v1.3에서는 별도 세계 ID뿐 아니라 원인이 전달되지 않는 관측법칙, diagnostic 위치와 효과 위치의 관계, 현실적인 비용비, 더 약한 오류 크기를 고정해야 한다. 독립 사람이 생성기 또는 평가 서버를 관리하는 외부 평가가 가능하지 않다면 로컬 잠금의 한계를 계속 공개한다. 결과가 나온 뒤 선택한 ‘후속 가설’을 이미 사전등록한 가설로 표기하지 않는다.

원 연구 H1/H2의 제한된 측정모형·획득 검증은 확장됐다. H3은 출처·학습 경로 분리만, H4 계층적 개체차는 미구현이다. H5 멀티피델리티는 v1.1 기능을 보존했지만 이번 연구에서 추가 검증하지 않았다. H6은 유한 진단 검정만 확장했으며 적응 수집의 예측구간에 분포무관 보장을 부여하지 않았다. 실제 생물 데이터, ODE·SINDy·PINN·기반 모델 학습은 계속 범위 밖이다.
