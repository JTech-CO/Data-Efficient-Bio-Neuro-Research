# 18. 세 후속 연구의 설계와 해석 경계

**v1.3.0-research.1 / 실제 생물학적 관측 0개.** 기존 01~17장과 v1.0~v1.2 코드는 수정하지 않는다. 본 버전은 16장의 D/E/F를 독립적으로 검증하는 연구 모듈이다. 이 세 모듈이 하나의 프로덕션 시스템으로 완전히 통합됐다는 뜻은 아니다.

## 연구 질문과 실행 범위

| 과제 | 질문 | 비교 | 실제 구현 |
|---|---|---|---|
| D | 교정이 표본에 전달된다는 가정을 어떤 관측으로 검사하는가? | 외부 표준, 표준 첨가, 배경 공백, 독립 기준, 삼각 비교 | 선형 관측계·물리 매개변수의 rank, 오차, 조건부 식별과 가정 충돌 |
| E | 같은 진단비로 고정 지점 사이의 국소 오류를 더 잘 찾는가? | 세 지점, 균일, 층화, 최대 간격, 적응 탐색 | 새 표본-대조 대비, 위치 선택, 유한 Bonferroni와 alpha spending |
| F | 잡음 추정과 수집 정책 중 무엇이 개선을 만들었는가? | 3개 수집 추정기 × 3개 정책 × 3개 최종 추정기 | 동일 데이터 재적합, 고정 추정기의 정책 교체, NLL·CRPS·포함률·폭 |

## 데이터와 권한 분리

`World`는 실행기만 소유한다. D 적합 함수에는 관측만, E 위치 정책에는 이전의 대비값과 공개 좌표·예산만, F 정책에는 적합 모델과 과거 학습 관측만 전달한다. 숨은 오류 위치, 실제 gain, 잡음 생성 법칙, 최종 테스트 값은 선택 함수의 인자가 아니다.

관측에는 원본 ID, kind, x, delta, 비용, 기술적 반복 인덱스, fit/audit/test, 부모 ID, simulated 출처를 보존한다. 생성·대체값, 실제 표본, 실제 실험 승인을 받는 입력은 거부한다. 같은 조건 반복은 새로운 독립 생물 개체가 아니다. 좌표는 측정 전에 소수점 10자리로 정규화해 반복 계보의 부동소수점 모순을 막는다.

실행은 수집 종료 후 동결 이벤트를 남기고 그 뒤에만 테스트를 연다. D와 F는 각각 최종 측정 33개와 81개의 비용을 따로 기록한다. E는 진단용 관측만 사용하며 최종 성능은 시뮬레이터의 오류 위치에 대한 수치적 평가이다. E에 임상·생물학적 정확도나 별도 실측 테스트 비용을 꾸며 넣지 않는다.

## 실행 전 고정과 수정 이력

38개 개발 smoke run 뒤 코드·설정·개발 결과 해시를 고정한다. 외부 사전등록, 외부 블라인드, 독립적인 생성기 운영자는 없다. 생성기는 개발자에게 알려져 있으며 결과는 탐색적 합성 연구다.

첫 부분 평가 `evaluation-v130-b`는 같은 좌표를 반올림한 반복 키와 반올림하지 않은 실제 좌표가 충돌하여 계보 검사에서 중단됐다. D 결과 일부를 진행 확인용으로 본 뒤 이 구현 오류를 수정했다. 숫자 적합법·정책·검정 임계값은 바꾸지 않았고, 평가 bank와 시드를 `evaluation-v130-c`, 41000부터로 바꿔 전체를 다시 실행했다. 실패 로그·원 코드·원 잠금·부분 결과 해시는 `research/triad/quality/aborted_attempt/`에 보존한다. 부분 원시 스트림은 최종 패키지에 중복 배포하지 않는다. 이 수정 이력을 숨기거나 최종 평가가 어떤 결과도 보지 않은 확인 연구라고 표현하지 않는다.

## 공정 비교와 중단

D의 수집 비용은 프로토콜마다 48이다. 더 비싼 기준 측정은 일반 측정 횟수를 줄인다. E는 진단 예산과 대조 비용을 동일하게 맞춰 위치 정책을 비교한다. 진단 비용은 이동비·실험 준비비까지 모델링한 실제 비용이 아니라 명시된 합성 단위다. F는 학습 비용 48에서 모든 수집 결과에 세 추정기를 다시 맞춘다. 무작위·공간 채우기는 수집 추정기에 의존하지 않으므로 중복된 데이터셋을 독립 증거로 계산하지 않는다.

세 모듈 모두 첫 경고만으로 자동 중단하지 않는다. D는 주장의 조건을 표시하고, E는 동일 예산까지 진행하며 첫 경고 비용을 기록한다. 실패나 더 나쁜 결과를 제거하지 않는다. 일찍 경고했다는 사실과 더 적은 실험비로 정확한 예측을 만들었다는 주장은 분리한다.

## 통계 해석

세계별 기전 계수·오류 크기·잡음을 바꾸고 같은 세계를 정책끼리 짝짓는다. 비율에는 Wilson 구간, F의 계획된 비교에는 1,000회 세계 bootstrap 기술 구간을 제공한다. 다중 비교 보정 우월성 검정이나 실제 donor 모집단의 신뢰구간이 아니다. 간단한 기준선보다 못한 셀도 모두 공개한다.

원 H4의 계층적 개체차, ODE·SINDy·PINN, 기반모델 미세조정, 실제 데이터 권한·보관정책, 실험 장치 제어는 범위 밖이다. H6 역시 제한된 E 진단 규칙 외에 예측구간의 분포무관 보장을 얻지 않는다.
