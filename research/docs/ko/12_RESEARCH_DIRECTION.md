# 12. 다음 연구 방향과 반증 조건

[English](../en/12_RESEARCH_DIRECTION.md) · [원 연구 가설](../../../docs/ko/06_RESEARCH_AGENDA.md) · [현재 결과](11_PILOT_RESULTS.md)

## 방향성 결정

다음 단계의 핵심 질문은 **“가정이 틀렸음을 언제 알아차리고, 원인을 구분할 다음 측정을 어떻게 고를 것인가?”**로 좁힌다. 이는 더 큰 범용 회귀 모델이나 생물 파운데이션 모델을 곧바로 추가하는 계획보다 현재 실패 결과와 직접 연결된다. 원 연구 계획의 보존과 실제 작은 구현의 반복을 우선한다.

다음 버전을 새로운 바이오 AI의 완성으로 부르지 않는다. 본 버전은 관측 연산자와 후보 집합의 중요성을 드러내는 정적 합성 문제들이다. 아직 실제 신경 신호나 세포 동역학을 학습하지 않았다. 생물 데이터가 생기기 전에도 가정 오류 진단과 실험 설계의 반증 가능한 연구는 계속할 수 있다.

## 원 가설과 현재 구현의 대응

| 가설 | 구현 상태 | 아직 주장할 수 없는 것 |
|---|---|---|
| H1: 관측 가능한 후보 차이에 기반한 획득 | 유한 A/B 기전, 관측 투영 MI, 후보 밖 참값 시험 | 미지 기전의 탐색·발견, 일반적인 최적 실험설계 |
| H2: 관측모형 개선의 효과 | 선형 known-H, identity 제거 비교, 같은-query 재적합 | 미지 센서의 H 추정, PINN/UDE보다 우수함 |
| H3: 증강 출처와 독립 증거 분리 | lineage·split·fit 차단 검사 | 생성 증강의 효과 크기, 개인정보 보호 |
| H4: 공유 구조와 개체차 | 미구현 | donor 일반화, 계층적 Bayesian 동역학 |
| H5: 해로운 fidelity 전이 회피 | 공동 GP, pooling/HF-only 기준선, 전환 게이트 | 여러 실제 소스의 자동 등급 판별, 전환의 보편적 이점 |
| H6: 적응적 수집 후 불확실성 | NLL·포함률·폭, 진단 중단 | conformal·anytime·distribution-shift 보장 |

## 연구 작업 A: 가정 탐지기 자체를 평가한다

현재 게이트는 잔차 기준과 소수 validation 지점을 이용한다. 이는 구현 결정을 가능하게 하는 휴리스틱이며, 편향을 놓치거나 올바른 모형을 의심할 수 있다. 다음 연구에서는 오류가 없는 세계와 오류가 있는 세계를 분리한 숨긴 synthetic bank를 만든다.

한 번에 바꾸는 축은 센서 gain/offset, 비선형 관측, 이분산 noise, heavy tail, 국소 불연속, 후보식 누락, LF/HF 관계 변화다. 학습용 시나리오와 최종 평가용 함수 family를 분리한다. 진단 횟수가 늘어나며 생기는 false alarm도 측정한다.

**반증 조건:** 가정 게이트가 기본 획득 대비 예측 손실을 줄이지 못하면서 정상 세계에서 높은 중단률을 만든다면, 자동 중단을 채택하지 않는다. 경고만 남기는 모드, 추가 진단 측정을 요청하는 모드와 비교한다. 임계값은 별도 개발 bank에서 고정하고 최종 bank에서는 바꾸지 않는다.

**산출물:** 가정 상태 truth tag가 있는 fixture bank, false-positive/false-negative/stop-delay 표, 총비용·추가측정수·예측손실의 동시 보고. 특정 수치의 개선 목표는 지금 결과를 보고 사후로 설정하지 않는다.

## 연구 작업 B: 더 많이 측정하는 대신 측정 종류를 바꾼다

현재 선택 readout은 이미 알려진 H다. 다음에는 “기전 계수”와 “센서 gain”이 모두 미지인 작은 계를 만들어 관측 불확실성까지 포함한다. 같은 조건 반복, 독립 센서 교정, 선택 readout, 알려진 synthetic intervention을 다른 action으로 둔다.

모형 구분 정보이득과 센서 교정 정보이득을 분리해서 기록하고, 어느 정보가 줄었는지 나타낸다. 단순 반복이 잡음을 줄여도 구조적 혼동은 풀지 못하는 경우를 유지한다. 기전·센서 두 블록의 posterior를 무조건 단일 숫자 uncertainty로 합치지 않는다.

**반증 조건:** 새 획득이 같은-query known-H 또는 oracle-H 참조와 비교해도 실질적 이득이 없고 계산비만 늘면, 단순한 교정-후-회귀 경로를 유지한다. 식별되지 않은 계수에는 숫자 하나보다 동등한 해 집합을 보고한다.

## 연구 작업 C: 시간을 도입하되 모듈을 한 번에 늘리지 않는다

정적 폐루프의 검사가 안정화된 뒤 2상태 ODE toy family와 부분 관측을 추가한다. 고정기전 수치적 적합, GP 또는 작은 residual, weak-form 후보 동역학 순서로 비교한다. noise 추정과 시간 선택을 동시에 추가하지 말고 단계적으로 제거 비교한다.

현재 `time=1.0` 제한을 완화할 때 Query schema, 생성기, 적분오차, 평가 시간축과 미래외삽 분할을 함께 바꿔야 한다. 구현된 것처럼 빈 플러그인 이름만 추가하지 않는다.

**반증 조건:** 새 동역학 모형이 알려진 단순 ODE+관측 likelihood 기준선보다 재현성·오차·해석에서 나아지지 않으면, 복잡성을 올리지 않는다. 진짜 생물 기전의 발견 여부는 여전히 별도 문제다.

## 데이터 접근이 가능해진 이후의 경계

현재 adapter는 real을 받지 않는다. 실제 파일을 넣을 수 있게 바꾸려면 단순 CSV uploader가 아니라 단위·장비·readout 정의, 사용권한, donor/session/site 분할, 불완전한 라벨과 전처리 lineage, 보관·삭제 정책을 먼저 정의해야 한다. 이미 있는 데이터의 pool replay는 새로운 개입의 효과를 증명하지 않는다. 선택할 수 있었던 실제 관측의 범위 안에서만 replay한다.

공개 데이터에서 방향이 확인되어도 prospective 실험과 임상적 사용은 별도 승인·설계·검증의 대상이다. 이 버전은 해당 작업을 수행하지 않는다.

## 저장소 운영 원칙

01~08 원 계획을 과거 구현 결과에 맞춰 덮어쓰지 않는다. `research/docs/`에 새 결정과 근거를 축적한다. 각 연구 버전마다 config, 코드 해시, 전체 결과와 실패 사례를 묶고, 개발용 결과와 잠긴 최종 결과를 구분한다. UI의 장식보다 무엇이 관측·가정·계획인지 식별 가능해야 한다.

다음 작업은 A와 B가 우선이다. H4나 파운데이션 모델, 새로운 생물 데이터 통합을 먼저 시작하는 것은 현재의 핵심 실패 원인을 해결하지 못할 수 있다. 이 우선순위는 이번 파일럿에 근거한 연구 설계 판단이지 검증된 일반적 최적 순서가 아니다.
