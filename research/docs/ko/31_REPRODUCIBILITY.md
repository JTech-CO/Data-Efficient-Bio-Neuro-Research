# 31. 재현성·문서 정리·검증 범위

[English](../en/31_REPRODUCIBILITY.md) · [실행 안내](../../../BOUNDED.md) · [상세 QA](../../bounded/quality/QA.md)

## 재현 단위와 동결

개발 실행 60개를 포함한 `prepare` 뒤 수치 소스·설정·계획·개발 결과 해시를 고정했다. 평가 후 문서와 뷰어는 작성했지만 동결한 수치 코드는 수정하지 않았다. 8,208개 실행은 같은 알려진 합성 가족의 새로운 시드 평가이며, 외부 독립 사전등록·생물학 블라인드 평가가 아니다. G의 최종 평가는 분석적 참값 비교, H/I는 모형과 bootstrap을 동결한 후 새로운 최종 관측을 공개한다.

`raw/G.jsonl.gz`, `H.jsonl.gz`, `I.jsonl.gz`에 모든 원시 기록이 있다. 각 실행은 관측·비용·역할·가정·평가와 해시를 포함한다. `summary.json`은 363셀, `paired.json`은 사전에 지정한 같은 세계 비교다. 대표 105개만 뷰어에 표시하지만 나머지 결과를 버리지 않는다. 원본은 gzip JSON Lines이고 별도 복원 알고리즘이 필요 없다.

## 검증 결과

기존 181개와 신규 32개, 총 213개 테스트가 통과했다. 모든 8,208개 기록, 1,575,072건의 직렬화 관측, 모든 집계와 짝지은 비교를 재검산했다. 대표 105개는 전체 다시 계산하여 동일함을 확인했다. 관측 건수는 정책·설계 간 사용된 기록을 포함하며 독립 생물 표본 수가 아니다. G 허용 폭의 집합 포함 관계, H의 같은 비중에서 동일 학습 자료, I의 순수오차 분해를 함께 검사했다. 별도 G/H/I 공개 demo 명령도 실행했다.

브라우저의 실제 localhost 접속을 시도했으나 환경 관리 정책에 차단됐다. 이후 정확한 배포 자산을 주입하여 126개 검사와 화면 렌더링을 수행하고, HTTP JSON 전송을 별도로 확인했다. 실제 브라우저 URL 접속부터 다운로드까지의 전체 과정, Windows/macOS 설치, 원격 Pages 배포는 검증하지 않았다. 초기 실패 로그를 보존했다. 검증 스크립트 최초 동기 실행의 시간 초과는 완료된 후속 전수검사와 구분하며 수치 평가를 수정·선별한 사유가 아니다.

## README 정리

`README.md`와 `README.en.md`에는 현재 버전, 프로젝트 설명, 세 연구 입구, 실행 방법만 남겼다. 누적 버전 확인은 `VERSIONS.md`와 `VERSIONS.en.md`로 옮겼다. 기존 README 두 개와 체크섬 원문은 `research/bounded/baseline/`에 바이트 그대로 보존했다. 아카이브 원문의 상대 링크는 재작성하지 않았으므로 활성 링크 탐색은 VERSIONS를 사용한다.

기준은 직전 `v1.3.0_Transport-Audit-Noise_KO-EN.zip`이다. 기본 1,132파일 중 README 두 개와 root checksum 외에는 변경하지 않는 구조다. 실제 파일 수와 ZIP 크기·SHA-256·추가분 병합 일치는 패키징 검증 JSON의 값을 따른다. 이후 원격 저장소를 수정했다면 전체 ZIP을 덮어쓰기 전에 diff해야 한다. 원격 GitHub는 조회·커밋·배포하지 않았다.

## 학술·실무 경계

참고문헌은 Consensus 검색과 fetch, 저자·출판사·NIST의 공개 자료를 구분해 기록했다. 초록만 확인한 논문을 전체 재현했다고 쓰지 않는다. 라이선스와 저자 정보는 기존 저장소 정책을 유지한다. 실제 측정 오차 범위와 독립성은 코드가 인증하지 않으며 프로덕션 모델·실험실 자동화의 안전성을 이 테스트로 주장하지 않는다.
